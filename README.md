# 🎓 Bright Future Academy

A modern, responsive coaching website built for students of Class 5 to Class 10, showcasing courses, faculty, testimonials, and an easy way for parents/students to get in touch.

## 🔗 Live Demo
https://tiwarideeksha522-byte.github.io/Bright_future_coaching_classes/

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## ✨ Features
- 🏠 Home page with an introduction and key highlights
- 📊 Results section showing student performance stats
- ℹ️ About section covering teaching approach and values
- 📚 Courses section for Class 5–7, 8–9, and 10 batches
- 👩‍🏫 Faculty section introducing the teaching staff
- 🖼️ Gallery showcasing the coaching environment
- 💬 Testimonials from parents and students
- ❓ FAQ section answering common queries
- 📩 Contact form and details for admission enquiries
- 📱 Fully responsive design (mobile & desktop friendly)

## 🚀 How to Run Locally
```bash
git clone https://github.com/tiwarideeksha522-byte/Bright_future_coaching_classes.git
cd Bright_future_coaching_classes
```
Then simply open index.html in your browser.
